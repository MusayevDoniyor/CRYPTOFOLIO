## 📌 Executive Overview

**CRYPTOFOLIO** is a high-performance decentralized financial intelligence platform engineered for real-time asset telemetry, portfolio diversification analysis, and market volatility tracking. Built with React 18, TypeScript, and Chart.js, it delivers sub-millisecond calculation updates and responsive multi-asset visualization.

## ✨ Core Architecture & Features

- ⚡ **Real-Time Asset Telemetry**: Dynamic live price feeds, 24-hour volume velocity, and percentage deltas across major cryptocurrencies.
- 📊 **Interactive Portfolio Distribution**: Dynamic doughnut and area charts powered by Chart.js for visualizing capital allocation and risk exposure.
- 💾 **Local-First Persistence**: Instant hydration with encrypted browser storage for zero-latency portfolio state recovery without third-party tracking.
- 📱 **Adaptive Cyber-Dark UI**: Engineered with Tailwind CSS and Flowbite for seamless cross-platform desktop, tablet, and mobile workflows.
- 🧮 **Precision Math Engine**: High-precision floating point accounting for micro-satoshis and fractional token quantities.

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Type Safety**: TypeScript 5
- **Data Visualization**: Chart.js + react-chartjs-2
- **Design Tokens**: Tailwind CSS + Flowbite React
- **Hosting & Edge Delivery**: Vercel

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/MusayevDoniyor/CRYPTOFOLIO.git

# Enter workspace
cd CRYPTOFOLIO

# Install dependencies
npm install

# Launch development environment
npm run dev
```
